# Módulo Web Dinámico en PHP

Proyecto que integra scripts de PHP modulares con una base de datos MySQL/MariaDB, aplicando buenas prácticas de seguridad (PDO y Prepared Statements) para prevenir Inyección SQL y ataques XSS.

## Tecnologías
- PHP 8+
- MySQL / MariaDB
- HTML5 & CSS3
- PDO (PHP Data Objects)

## Instalación Local
1. Clonar el repositorio en la carpeta `htdocs` (XAMPP) 
2. Importar el archivo `database.sql` en phpMyAdmin 
3. Abrir en el navegador: `http://localhost/AI3_DisenoWeb/`
